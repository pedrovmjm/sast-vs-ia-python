% Lista de abreviaturas e siglas
\begin{siglas}
\item[API] \textit{Application Programming Interface}: interface que permite a comunicação entre sistemas, aplicações ou serviços.
  
  \item[CE] \textit{Community Edition}: versão comunitária de uma ferramenta, geralmente gratuita ou aberta.
  
  \item[CI/CD] \textit{Continuous Integration / Continuous Delivery}: conjunto de práticas utilizadas para integração, testes, entrega e implantação contínua de software.
  
  \item[CLI] \textit{Command Line Interface}: interface de linha de comando utilizada para interagir com programas por meio de comandos textuais.
  
  \item[CSV] \textit{Comma-Separated Values}: formato de arquivo textual utilizado para representar dados em estrutura tabular.
  
  \item[CVE] \textit{Common Vulnerabilities and Exposures}: catálogo público de vulnerabilidades conhecidas em softwares, sistemas e bibliotecas.
  
  \item[CWE] \textit{Common Weakness Enumeration}: catálogo de fraquezas comuns de software utilizado para classificar tipos de vulnerabilidades.
  
  \item[DevSecOps] \textit{Development, Security and Operations}: abordagem que integra práticas de desenvolvimento, segurança e operações ao longo do ciclo de vida do software.
  
  \item[F1-score] \textit{F1 Measure}: métrica que combina precisão e revocação em uma única medida de avaliação.
  
  \item[F3-score] \textit{F3 Measure}: variação da métrica F-score que atribui maior peso à revocação, útil em contextos nos quais a não identificação de vulnerabilidades é mais crítica.
  
  \item[FN] \textit{False Negative}: falso negativo; ocorre quando uma vulnerabilidade real não é identificada pela ferramenta.
  
  \item[FP] \textit{False Positive}: falso positivo; ocorre quando a ferramenta indica uma vulnerabilidade inexistente ou não aplicável.
  
  \item[IA] Inteligência Artificial: área da computação voltada ao desenvolvimento de sistemas capazes de executar tarefas associadas à inteligência humana.
  
  \item[JSON] \textit{JavaScript Object Notation}: formato leve de representação de dados, utilizado para armazenar e trocar informações estruturadas.
  
  \item[LLM] \textit{Large Language Model}: modelo de linguagem de grande escala capaz de compreender e gerar texto, código e outros conteúdos.
  
  \item[OWASP] \textit{Open Worldwide Application Security Project}: organização voltada à promoção de boas práticas, materiais e projetos relacionados à segurança de aplicações.
  
  \item[PoC] \textit{Proof of Concept}: prova de conceito; implementação experimental utilizada para validar a viabilidade técnica de uma ideia ou abordagem.
  
  \item[PR] \textit{Pull Request}: solicitação de alteração em um repositório de código, geralmente utilizada para revisão antes da integração ao projeto principal.
  
  \item[RAG] \textit{Retrieval-Augmented Generation}: abordagem em que um modelo de linguagem utiliza informações recuperadas de fontes externas para gerar respostas mais contextualizadas.
  
  \item[SAST] \textit{Static Application Security Testing}: técnica de análise estática de segurança utilizada para identificar vulnerabilidades no código-fonte sem executar a aplicação.
  
  \item[TN] \textit{True Negative}: verdadeiro negativo; ocorre quando a ferramenta corretamente não indica vulnerabilidade onde ela não existe.
  
  \item[TP] \textit{True Positive}: verdadeiro positivo; ocorre quando a ferramenta identifica corretamente uma vulnerabilidade existente.
\end{siglas}
